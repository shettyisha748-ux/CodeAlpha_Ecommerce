# Django E-Commerce Website

## About
A simple e-commerce website built using Python and Django.

## Features
- View products
- Add products to cart
- Increase and decrease quantity
- Remove products from cart
- Checkout and place orders
- Order success page
- Django Admin for managing products and orders

## Technologies Used
- Python
- Django
- HTML and CSS
- SQLite

## How to Run
1. Install Django using `python -m pip install django`.
2. Run `python manage.py migrate`.
3. Create an admin account using `python manage.py createsuperuser`.
4. Start the server using `python manage.py runserver`.
5. Open `http://127.0.0.1:8000/` in your browser.

## Purpose
Created as a learning project for full-stack web development.
